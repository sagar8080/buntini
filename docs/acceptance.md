## Online and file boundaries

Web mode sends the explicitly approved query, never private file results. Retrieved text is untrusted data. Public research-page HTTP reads accept selected public HTTPS URLs, revalidate and pin DNS, verify the connected peer, and disable proxies, redirects, cookies, credentials, scripts, and subresources. HTML/text sizes and deadlines are bounded. Unsupported pages show errors rather than invented content. See [online tool details](online-tools.md).

Price watches use published Schema.org offers with decimal-string amounts and explicit currencies. Ambiguous products, conflicting quotes/stock/sellers, aggregate ranges, and unsupported metadata cannot produce a threshold alert. There is no currency conversion or checkout-total guarantee. Pausing/deleting cancels the active monitor and prevents later retries/notices through its cancellation state.

File scans are limited to approved roots, 10,000 entries, 40 hits, and 64 KB of text per file. PDF, Word, RTF and Pages text comes from the Apple helper, which receives the bytes of a file Buntini opened in scope (at most 32 MB), caps pages, characters and time, and parses with no network, file writes or access to the user's folders. Index rebuilds are bounded to 5,000 files/20 MiB and atomic; indexed hits reopen current files within current grants. Search also performs the same bounded scoped live walk to discover new files; an explicit rebuild still refreshes the saved index snapshot. Neither cached index text nor remote page text becomes tool authority.

The separate browser workspace additionally uses a persistent, isolated WebKit profile per approved origin with a required public-IP proxy. It reads rendered text after approval; its bounded observation does not prove authentication or any website transaction. See [capabilities](capabilities.md).
